# 🎬 映画ワークフロー ➡️ 👤 人物ワークフロー 呼び出し設定手順

映画の登録完了時に、出演キャスト全員（10〜40名）および監督を自動で **『人物用データベース充実ワークフロー』** に引き渡し、顔写真・Wikidata QID・バイオグラフィ・SNSを人物DB（`Persons`）に自動登録させる設定手順です。

---

## 1. 子ワークフロー（人物用データベース充実ワークフロー）の準備

### ① `Execute Workflow Trigger` ノードの追加
- 人物ワークフローの先頭に **`Execute Workflow Trigger`** ノードを配置します。
- その出口を **`入力分割コード`** に繋ぎます。
  ```text
  [Execute Workflow Trigger] ──┐
                               ├──➡ [入力分割コード] ➡️ [Wikidata検索] ➡️ ...
  [When Form Submitted (既存)] ──┘
  ```
  *(※ Formトリガーと並行して両方から `入力分割コード` に繋げておけば、手動フォームからも映画からも両方受け付けられます)*

## 2. 親ワークフロー（映画無限検索ワークフロー）の設定

### ① `Execute Workflow` ノードの配置
- `Supabaseへ保存` ノードの直後に **`Execute Workflow`** ノードを配置し、接続します。
- ノード名を **`人物充実ワークフロー呼び出し`** に変更します。

### ② ノードパラメータ設定
- **Workflow**: `人物用データベース充実ワークフロー`（ドロップダウンから選択、または Workflow ID を入力）
- **Wait for Sub-Workflow to Finish**: `ON`（確実に1本ずつ登録）または `OFF`（バックグラウンドで並行登録）
- **Mode**: `Custom JSON`（または `All Incoming Data`）
- **Custom JSON / Values to Send**:
  ```json
  {
    "director": "{{ $('映画データ整形Code').first().json.director }}",
    "director_en": "{{ $('映画データ整形Code').first().json.director_en }}",
    "cast": "{{ $('映画データ整形Code').first().json.cast }}",
    "cast_en": "{{ $('映画データ整形Code').first().json.cast_en }}",
    "country": "{{ $('映画データ整形Code').first().json.country }}"
  }
  ```

---

## 3. 実行時の動作フロー

```text
【映画ワークフロー】
[映画データ整形] ➡️ [Supabase(Movies)保存]
                           ⬇
             [人物充実ワークフロー呼び出し]
                           ⬇（cast: チョン・ジヒョン, ク・ギョファン... を送信）
【人物ワークフロー】
[入力分割コード]（キャスト20人を1人ずつ個別アイテムに自動分解）
       ⬇
[Wikidata検索 (SPARQL)]（顔写真・QID・生年月日・性別を取得）
       ⬇
[Wikipedia記事取得]（バイオグラフィ・解説を抽出）
       ⬇
[Supabase(Persons) Upsert]（全員の顔写真と詳細プロフィールを保存！）
```

これで、映画が保存されるたびに **キャスト・監督全員の顔写真と詳細データが自動で Persons テーブルに充実登録** されます！
