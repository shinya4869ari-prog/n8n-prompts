【あらすじあり？ (Switch / IF ノード) 用コード】

※ AIノード（キャスト・監督翻訳AI）を経由したことでn8nの.itemペアリングが切れている場合でも、安全に「映画データ整形コード」のあらすじを取得する完成版式です。

```javascript
{{ (() => {
  let overview = '';
  try {
    const d = $('映画データ整形コード').first()?.json || $('映画データ整形コード').item?.json || {};
    overview = $json.overview || d.overview || '';
  } catch(e) {}
  
  if (!overview || String(overview).trim().length < 20) return false;
  
  // ひらがな・カタカナ・漢字が含まれており、ハングル文字でなければ「日本語あらすじ有り」と判定
  const isJapanese = /[\u3040-\u30ff\u3400-\u4dbf\u4e00-\u9fff]/.test(overview);
  const isHangul = /[\uac00-\ud7af]/.test(overview);

  return isJapanese && !isHangul;
})() }}
```
