【あらすじあり？ (Switch / IF ノード) 用コード】

※ n8nのExpression（{{ }}）がJavaScriptの戻り値を文字列化するのを防ぎ、純粋なBoolean(true/false)に変換するために末尾に `.toBoolean()` を付与します。

```javascript
{{ (() => {
  let overview = '';
  try {
    overview = $json.overview || $('映画データ整形コード').item?.json?.overview || '';
  } catch(e) {}
  
  if (!overview || String(overview).trim().length < 20) return false;
  
  // ひらがな・カタカナ・漢字が含まれており、ハングル文字でなければ「日本語あらすじ有り」と判定
  const isJapanese = /[\u3040-\u30ff\u3400-\u4dbf\u4e00-\u9fff]/.test(overview);
  const isHangul = /[\uac00-\ud7af]/.test(overview);

  return isJapanese && !isHangul;
})().toBoolean() }}
```

---

### 📋 n8n ノード設定（Parameters）
1. **Conditions 型**: `Boolean`
2. **ルール**: `is true`
3. **`Convert types where required`**: OFF（オフ / 灰色）
