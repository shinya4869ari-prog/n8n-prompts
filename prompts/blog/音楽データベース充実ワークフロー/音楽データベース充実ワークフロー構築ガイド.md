# 🎵 個別アーティスト・音楽データベース充実ワークフロー構築ガイド

個別のアーティスト・グループ名（例: `BLACKPINK`, `BTS`, `米津玄師`）を入力とし、代表曲・高画質ジャケット・グループ構成メンバー（ジス、ジェニー等）を自動取得して Supabase の `Persons` および `Music` テーブルへ全自動保存する専用ワークフローの設定マニュアルです。

---

## 1. ワークフロー全ノード構成

```
[Form Trigger / 入力 (Artist: BLACKPINK)]
   │
   ├─► [iTunes検索] (HTTP Request: https://itunes.apple.com/search?term={{$json.artist}}&entity=song&limit=10)
   ├─► [Wikidataメンバー検索] (HTTP Request: Wikidata SPARQL + User-Agentヘッダー)
   │
   ▼
[iTunes_Wikidata_Music_Enhancer] (Codeノード)
   │
   ├─► [Persons_Music_Supabase_Upsert] (Codeノード)
   │      │
   │      ▼
   │   [Personsへ保存] (HTTP Request: https://uvjpiuinsgklddzhzpio.supabase.co/rest/v1/Persons?on_conflict=name)
   │
   ▼
[Musicへ保存] (HTTP Request: https://uvjpiuinsgklddzhzpio.supabase.co/rest/v1/Music?on_conflict=artist_name)
```

---

## 2. 各 HTTP Request ノードの設定値

### ① `Wikidataメンバー検索` ノード
* **Method**: `GET`
* **URL**: (※`?group` も取得するように最適化された最新URL)
  ```text
  https://query.wikidata.org/sparql?query=SELECT%20DISTINCT%20%3Fgroup%20%3Fmember%20%3FmemberLabel%20%3FmemberEnLabel%20%3FmemberKoLabel%20%3FmemberImage%20%3FgenderLabel%20WHERE%20%7B%0A%20%20%3Fgroup%20rdfs%3Alabel%20%22{{encodeURIComponent($json.artist || $json['アーティスト名 / グループ名'] || $json.body?.['アーティスト名 / グループ名'] || 'BLACKPINK')}}%22%40ja%20.%0A%20%20%7B%20%3Fmember%20wdt%3AP463%20%3Fgroup%20.%20%7D%0A%20%20UNION%0A%20%20%7B%20%3Fgroup%20wdt%3AP527%20%3Fmember%20.%20%7D%0A%20%20OPTIONAL%20%7B%20%3Fmember%20wdt%3AP18%20%3FmemberImage%20.%20%7D%0A%20%20OPTIONAL%20%7B%20%3Fmember%20wdt%3AP21%20%3Fgender%20.%20%7D%0A%20%20OPTIONAL%20%7B%20%3Fmember%20rdfs%3Alabel%20%3FmemberEnLabel%20.%20FILTER(LANG(%3FmemberEnLabel)%20%3D%20%22en%22)%20%7D%0A%20%20OPTIONAL%20%7B%20%3Fmember%20rdfs%3Alabel%20%3FmemberKoLabel%20.%20FILTER(LANG(%3FmemberKoLabel)%20%3D%20%22ko%22)%20%7D%0A%20%20SERVICE%20wikibase%3Alabel%20%7B%20bd%3AserviceParam%20wikibase%3Alanguage%20%22ja%2Cen%2Cko%22.%20%7D%0A%7D%20LIMIT%2020&format=json
  ```
* **Send Headers**: `ON`
* **Headers**:
  - `User-Agent`: `Mozilla/5.0 (Windows NT 10.0; Win64; x64) n8n-music-app/1.0`

---

### ② `Personsへ保存` ノード
* **Method**: `POST`
* **URL**: `https://uvjpiuinsgklddzhzpio.supabase.co/rest/v1/Persons?on_conflict=name`
* **Headers**:
  - `apikey`: `<YOUR_SUPABASE_ANON_KEY>`
  - `Authorization`: `Bearer <YOUR_SUPABASE_SERVICE_ROLE_KEY>`
  - `Prefer`: `resolution=merge-duplicates`
* **Send Body**: `ON`
* **Body Content Type**: `JSON`
* **Specify Body**: `Using JSON`
* **JSON**: `={{ $json }}`
