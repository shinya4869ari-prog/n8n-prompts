# 音楽検索サブワークフロー 構築＆`main-blog-lowcost` 連携ガイド (iTunes Search API版)

このワークフローは、**完全無料・登録不要の iTunes Search API** を利用して対象国の代表曲・人気楽曲を取得し、AIスクリーニングを通じて「⑩ おすすめ音楽」セクション用データを自動生成するサブワークフローです。

---

## 🛠️ n8n ノード接続構造

```
[Execute Workflow Trigger / Form Trigger (country)]
       │
       ▼
[country-master-lookup] (Codeノード: 国名・ISOコード変換)
       │
       ▼
[iTunes検索_クエリ作成] (Codeノード: API URL生成)
       │
       ▼
[iTunes API Search] (HTTP Requestノード: GET https://itunes.apple.com/search)
       │
       ▼
[iTunes結果整形コード] (Codeノード: 高解像度ジャケット & 試聴URL抽出)
       │
       ▼
[Music_AI_Screener] (AIノード: 無関係な曲の除外 & 楽曲解説追加)
       │
       ▼
(結果の recommend_music リストを呼び出し元へ返却)
```

---

## ⚙️ iTunes API (HTTP Request ノード) の設定

- **Authentication**: `None` (認証不要！)
- **Method**: `GET`
- **URL**: `={{ $json.itunes_search_url }}`

APIキーやクライアントIDの登録は一切必要ありません。そのままリクエストを実行できます。

---

## 🔗 `main-blog-lowcost` からの呼び出し方法

1. **Execute Workflow ノードの追加**:
   - `main-blog-lowcost` ワークフロー内で、`researcher1` や `Supabase映画データ` と並行して `Execute Workflow` ノードを設置します。
   - サブワークフロー「音楽検索ワークフロー」を指定し、`country` を渡却します。

2. **JSON結合 (`リサーチデータ整形.js` / `整形ノード１.js`)**:
   - `Execute Workflow` の返り値（`recommend_music`）を `対象国データ_記事.おすすめ音楽` にマッピングします。

3. **`writer.md` の更新**:
   - ⑩ セクションとして以下の形式で出力させます：
     `音楽｜曲名：【曲名】｜アーティスト：【アーティスト名】｜リリース年：【年】｜preview_url：【preview_url】｜itunes_url：【url】｜ジャケット：【image_url】｜概要：【解説】`

4. **`最終Code.js` & `section_wp_updater.js` の対応**:
   - `音楽｜` の行をパースし、オーディオ再生プレイヤー (`<audio controls src="{preview_url}"></audio>`) と高画質ジャケット付音楽カード HTML を生成。
   - `<!-- SECTION:music:START -->` ... `<!-- SECTION:music:END -->` タグ内に置換挿入。
