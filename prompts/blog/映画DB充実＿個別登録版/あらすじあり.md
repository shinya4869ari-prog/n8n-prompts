【あらすじあり？ (IF ノード) 用 条件式】

### 💻 `Value 1`（Expression `fx`）に貼り付けるコード

```javascript
{{ (() => {
  let overview = '';
  try {
    overview = $('映画データ整形コード').first()?.json?.overview || $('映画データ整形コード').item?.json?.overview || '';
  } catch(e) {
    try {
      overview = $('Supabaseから既存データを取得').first()?.json?.overview || '';
    } catch(e2) {}
  }
  return !!(overview && String(overview).trim().length > 10);
})() }}
```

※「Operation」は **`is true`**（または `Equal` ➔ `true`）のままでOKです。
