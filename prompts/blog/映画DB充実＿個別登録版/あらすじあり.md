【あらすじあり？ (Switch / IF ノード) 用コード】

n8nの「Boolean -> is true」条件で関数の戻り値 `false` が文字列 `"false"` とみなされてTrue分岐に誤送信されるバグを防ぐため、文字列の `'YES'` / `'NO'` で判定します。

---

### 📋 n8n 条件（Conditions）設定方法

1. **型選択**: `String`
2. **比較演算子 (Operator)**: `Equal` (等しい)
3. **左側 (Value 1 / 式 fx)**:
```javascript
{{ (() => {
  let overview = '';
  try {
    overview = $json.overview || $('映画データ整形コード').item?.json?.overview || '';
  } catch(e) {}
  
  if (!overview || String(overview).trim().length < 20) return 'NO';
  
  const isJapanese = /[\u3040-\u30ff\u3400-\u4dbf\u4e00-\u9fff]/.test(overview);
  const isHangul = /[\uac00-\ud7af]/.test(overview);

  return (isJapanese && !isHangul) ? 'YES' : 'NO';
})() }}
```
4. **右側 (Value 2 / 値)**:
```text
YES
```

---

### 💡 動作の仕組み
* **あらすじ有り（日本語）**: 式が `'YES'` を返し、右側の `YES` と一致するため **True Branch**（分岐0: 追加処理不要ルート）へ進みます。
* **あらすじ無し（空/韓国語）**: 式が `'NO'` を返し、右側の `YES` と一致しないため **False Branch**（分岐1: Brave Search ➔ AI生成ルート）へ100%正しく進みます！
