【あらすじあり？ (Switch / IF ノード) 用コード】

n8nのBoolean型の内部変換トラップを100%回避し、ドロップダウンメニューの `String` ➔ `is not empty`（空ではない）で確実に判定する完成設定です。

---

### 📋 ドロップダウンメニューでの選択手順

スクショのメニュー画面から以下を選択してください：

1. **左側カテゴリー（型）**: **`String`** をクリック
2. **右側メニュー（比較方法）**: **`is not empty`**（空ではない）をクリック

---

### 💻 コード（Expression `fx` に貼り付け）

```javascript
{{ (() => {
  let overview = '';
  try {
    overview = $json.overview || $('映画データ整形コード').item?.json?.overview || '';
  } catch(e) {}
  
  // あらすじが有れば 'HAS_OVERVIEW' を返し、無ければ空文字 '' を返す
  return (overview && String(overview).trim().length > 10) ? 'HAS_OVERVIEW' : '';
})() }}
```

---

### 💡 動作の確定保証
* **あらすじが有る時**: 文字列 `'HAS_OVERVIEW'` が返る ➔ `is not empty` が成立 ➔ **True Branch（上の補完ブリッジルート）へ**
* **あらすじが無い時**: 空文字 `''` が返る ➔ `is not empty` が不成立 ➔ **False Branch（下の Brave Search ➔ AIあらすじ生成ルート）へ100%流れる！**
