# あらすじ判定ノード (IFノード設定)

このファイルは、映画のあらすじが日本語であるかどうかを判定し、不要なAI翻訳プロセスをスキップさせるための **IFノード (あらすじ判定ノード)** の設定です。

---

## 1. コピペ用ノードJSON (n8n用)

以下のJSONコードブロックをコピーして、n8n Nangキャンバス上で **`Ctrl + V`（貼り付け）** を行うだけで、ノードが自動的に生成されます。

```json
{
  "meta": {
    "instanceId": "5cb8e63f692b41569f447fbd9f69e835"
  },
  "nodes": [
    {
      "parameters": {
        "conditions": {
          "string": [
            {
              "value1": "={{ (()=>{ const tmdb = $('TMDb検索').item?.json || $('Get TMDb Details').item?.json || {}; const jaOverview = tmdb.translations?.translations?.find(t => t.iso_639_1 === 'ja')?.data?.overview; if (jaOverview && jaOverview.trim().length > 0) return jaOverview; return tmdb.overview || ''; })() }}",
              "operation": "regex",
              "value2": "[\\u3040-\\u309F\\u30A0-\\u30FF\\u4E00-\\u9FFF\\u3005-\\u3006]"
            }
          ]
        }
      },
      "id": "is-overview-japanese-if-node",
      "name": "あらすじ判定ノード",
      "type": "n8n-nodes-base.if",
      "typeVersion": 1,
      "position": [
        600,
        300
      ]
    }
  ],
  "connections": {}
}
```

---

## 2. 手動で設定する場合のパラメータ

手動でノードを配置して設定する場合は、以下の通りに入力してください。

| 設定項目 (Property) | 設定値 (Value) |
| :--- | :--- |
| **Node Name** | `あらすじ判定ノード` |
| **Type** | `String` |
| **Value 1** (Expression) | `{{ (()=>{ const tmdb = $('TMDb検索').item?.json || $('Get TMDb Details').item?.json || {}; const jaOverview = tmdb.translations?.translations?.find(t => t.iso_639_1 === 'ja')?.data?.overview; if (jaOverview && jaOverview.trim().length > 0) return jaOverview; return tmdb.overview || ''; })() }}` |
| **Operation** | `Regex Match` (正規表現マッチ) |
| **Value 2** | `[\u3040-\u309F\u30A0-\u30FF\u4E00-\u9FFF\u3005-\u3006]` |

---

## 3. 分岐後の挙動
- **true (日本語判定あり)** ➡ あらすじが最初から日本語のため、そのまま [Format Movie Data](file:///c:/Users/shiny/.gemini/antigravity/scratch/n8n-prompts/prompts/blog/国ループ映画データベース/映画データ整形コード.js) ノードへ進みます。
- **false (日本語判定なし)** ➡ あらすじが非日本語（または無し）のため、`Tavily Search` および `Translate & Summarize` による翻訳・要約処理を実行してから [Format Movie Data](file:///c:/Users/shiny/.gemini/antigravity/scratch/n8n-prompts/prompts/blog/国ループ映画データベース/映画データ整形コード.js) へ進みます。
