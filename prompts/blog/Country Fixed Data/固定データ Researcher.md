# 【重要】調査の絶対ルール（Gemini Google検索最適化版）
1. **Google検索による最新事実の確認**: 
   - 提供されているGoogle検索機能を最大限に活用し、**最新年（{{ $now_year }}年、または直近の公表年度）の公式データ**を調査してください。
   - 自身の記憶や古い学習データだけに頼らず、必ずWeb上の最新情報を検索して回答を作成すること。
2. **正確性重視**: 
   - 記事の信頼性に関わるため、全ての数値データについて「最新年」「具体的な値」「出典」をセットで取得すること。
3. **推測・捏造の厳禁**: 
   - データが見つからない、または統計が存在しない場合は「欠測」と記載し、架空の数値を絶対に捏造しないこと。
4. **出典の記載方法**: 
   - 「出典」には純粋な機関・組織名（例:「UNODC」「警察庁」「Vision of Humanity」「The Economist」「Netflix公式」など）のみを記載してください。
   - 「10万人あたり」などの算出基準や単位、URLなどの余計な文字は含めないこと。
5. **純粋なJSONのみ出力**: 
   - 挨拶文、解説文、前置き、後書きは一切不要です。指定されたJSONフォーマットのみを出力してください。

# 調査項目

### 1. 治安・社会指標
- **GPI (Global Peace Index)**: Vision of Humanityの最新スコア、順位、年を取得。
- **外務省海外安全ホームページ**: 対象国の「危険レベル」を確認。
  - 4段階（0:白/危険なし, 1:黄/十分注意, 2:薄オレンジ/不要不急の中止, 3:濃オレンジ/渡航中止勧告, 4:赤/退避勧告）で数値化（0〜4の数値）。
  - 地域によって異なる場合は、最も高いレベルまたは首都のレベルを採用。
- **犯罪トップ5**: 発生件数または検挙件数が多い犯罪トップ5を日本語でリストアップ。最新年と出典（警察統計等）を明記。
- **女性・子供指標**:
  - 性的暴行届出率（10万人あたり）：値、年、出典
  - 年間性的暴行件数：値、年、出典
  - 人身売買被害者数：値、年、出典
  - **GGI (Global Gender Gap Index)**: WEFの最新スコア、順位、年を取得。

※以下の基本社会指標（World Bank APIで自動取得されますが、補完用として調査してください）：
- 殺人率（10万人あたり）、交通事故死亡率（10万人あたり）、自殺率（10万人あたり）、失業率（%）、貧困率（%）、ジニ係数

### 2. 物価・為替指標

#### ビッグマック価格
- クエリ例: `Big Mac price {{ $json.countryEn }} {{ $now_year }} OR official latest`
- 必ず最新の価格を取得し、出典にも機関名（The Economist等）を記載すること。

#### Netflix（スタンダードプラン価格）
- クエリ例: `Netflix standard plan price {{ $json.countryEn }} official latest`
- **絶対ルール**: 必ずNetflix公式（netflix.com または help.netflix.com）から取得すること。
- 現地通貨建ての価格を出力する際は、価格の前に通貨記号（例: `$14.99`, `€12.99`, `₩13,500` 等）を付与し、「通貨コード」に該当コード（例: USD, EUR, KRW）を記載すること。
- 価格が全く存在しない国は「欠測」と記載。

#### 為替レート（対日本円）
- クエリ例: `{{ $json.countryEn }} currency JPY exchange rate today`
- **絶対ルール**: 必ず「1外貨 ＝ 〇〇円」の形式（1外貨あたりの日本円数値）で出力すること。
- 対象国が「日本 (Japan)」の場合は為替レートは「1」を出力。
- **USD/JPY**: 「1USD ＝ 〇〇円」の数値を実勢レートで出力。
- **EUR/JPY**: 「1EUR ＝ 〇〇円」の数値を実勢レートで出力。
