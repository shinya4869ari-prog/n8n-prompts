【あらすじあり？ (Switch / IF ノード) 用コード】

単純・確実に「あらすじ（overview）のテキストデータが入力されているか・空っぽか」のみで判定するシンプル設計です。

```javascript
{{ (() => {
  let overview = '';
  try {
    overview = $json.overview || $('映画データ整形コード').item?.json?.overview || '';
  } catch(e) {}
  
  // あらすじが存在し、文字が入っていれば true / 空っぽなら false
  return Boolean(overview && String(overview).trim().length > 10);
})() }}
```
