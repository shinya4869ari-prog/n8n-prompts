# 【解説＆設定手順書】メインブログ 段階的キャッシュ保存＆スキップ自動化

## 📌 概要
本設計は、n8nによるメインブログ生成ワークフローにおいて：
1. **Perplexity依存を完全排除** し、全リサーチノードを **Gemini 3.8 Flash（Google検索連携・厳格JSON出力）** に統一。
2. リサーチ1・リサーチ2・リサーチ25（映画）の各工程を **Supabaseに即時保存（チェックポイント保存）**。
3. 途中でエラーが発生しても、**再実行時は「取得済みセクションを自動スキップ（0秒・0円）」** し、未取得セクションのみを自動継続する仕組みです。

## 🛠️ Step 1: Supabase側の作業台テーブル作成
Supabaseのダッシュボード ➜ **「SQL Editor」** に [country_research_cache_setup.sql](file:///c:/Users/shiny/.gemini/antigravity/scratch/n8n-prompts/prompts/blog/country_research_cache_setup.sql) の内容を貼り付けて「Run」を実行してください。

```sql
CREATE TABLE IF NOT EXISTS public.country_research_cache (
  country TEXT PRIMARY KEY,                       -- 国名（例: インドネシア）
  country_code TEXT,                              -- 国コード（例: ID）
  research1 JSONB DEFAULT NULL,                   -- リサーチ1（制度・地理・犯罪統計）
  research2 JSONB DEFAULT NULL,                   -- リサーチ2（歴史近代100年・最新動向）
  research25 JSONB DEFAULT NULL,                  -- リサーチ25（厳選映画10件＋歴史クロス解説）
  article_html TEXT DEFAULT NULL,                 -- 完成したブログ記事HTML
  status TEXT DEFAULT 'in_progress',              -- in_progress / completed / published
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE public.country_research_cache ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow all" ON public.country_research_cache FOR ALL USING (true) WITH CHECK (true);
```

### ② リサーチ1の判定 ＆ 即時保存
```text
[キャッシュ確認]
       │
       ▼
[IF: リサーチ1未取得？]
  ├─ (False / 取得済) ──▶ スキップして「IF: リサーチ2未取得？」へ直行
  └─ (True / 未取得)  ──▶ [researcher1 (3.8 Flash)] ──▶ [リサーチ1即時保存 (POST)]
                                                              │
                                                              ▼
                                                 [IF: リサーチ2未取得？]
```

* **[IF: リサーチ1未取得？] の条件式**:
  * Value 1: `{{ $('キャッシュ確認').first()?.json?.research1 || null }}`

  * **Method**: `POST`
  * **URL**: `https://uvjpiuinsgklddzhzpio.supabase.co/rest/v1/country_research_cache?on_conflict=country`
  * **Headers**:
    * `Prefer`: `resolution=merge-duplicates,return=representation`
    * `apikey`: `sb_publishable_iW0cu7wjxn_rKjAd1O5Prg_tmecdAkX`
    * `Authorization`: `Bearer sb_publishable_iW0cu7wjxn_rKjAd1O5Prg_tmecdAkX`
  * **Body Parameters**:
    ```json
    {
      "country": "{{ $('キャッシュ確認').item.json.country || $json.country }}",
    ```

## 🎯 達成されるメリット
1. **Perplexity完全不使用・完全無料枠対応**:
   * すべての調査が Gemini 3.8 Flash（Google検索内蔵）で完結。
2. **エラー時の損失ゼロ**:
   * 途中でどこかのノードが止まっても、それまでに取得したセクションはSupabaseに保存済み。
   * 再実行時は取得済みの工程が自動スキップされるため、APIトークンや時間を一切無駄にしません。
3. **段階的な記事育成**:
   * 「リサーチ1・2だけ先に全自動で溜めておき、週末に映画やライターを回す」といった柔軟な分割運用が可能になります。
