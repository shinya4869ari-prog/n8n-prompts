# 📑 ★まとめ記事即時保存 ノード設定ガイド（PATCH方式・完全自動化）

n8nワークフロー上の **「★まとめ記事即時保存」**（HTTP Requestノード）の決定版設定です。  
過去のセクションデータ（リサーチ1・2・映画など）には一切触れず、**今回新しく生成された「まとめ記事（5大特集）」だけを、対象国の行へピンポイントで追加保存（PATCH）** します。

---

## ⚙️ 基本設定

* **Node Name**: `★まとめ記事即時保存`
* **Method**: **`PATCH`** （※新規作成ではなく、既存の行にまとめ記事を追加するため）
* **URL**:
  ```text
  https://uvjpiuinsgklddzhzpio.supabase.co/rest/v1/country_research_cache?country=eq.{{ encodeURIComponent($('国名変換Code').first()?.json?.country || $('まとめCode').first()?.json?.country) }}
  ```
  ※国名（インドネシア、タイ、アメリカ等）は変数から全自動で入るため、国が変わっても手動で書き換える必要は一切ありません。

---

## 📋 Headers 設定

| Header名 | 値 | 役割 |
| :--- | :--- | :--- |
| `apikey` | `sb_publishable_iW0cu7wjxn_rKjAd1O5Prg_tmecdAkX` | Supabase APIキー |
| `Authorization` | `Bearer sb_publishable_iW0cu7wjxn_rKjAd1O5Prg_tmecdAkX` | Bearerトークン |
| `Content-Type` | `application/json` | JSON送信指定 |

※`Prefer` ヘッダー（`resolution=merge-duplicates` など）は **不要** です。PATCHなので重複エラー（409）は構造上絶対に起きません。

---

## 📦 JSON Body 設定

### 【推奨】Specify Body: `JSON` ➜ 「Expression」モード
以下のコードブロックをそのまま「JSON」入力欄に貼り付けてください。  
**過去のデータや国名は送らず、今回新しくできた `summary_article`（まとめ記事本文）だけ** を保存します。

```javascript
{{
  JSON.stringify({
    summary_article: $json.content?.parts?.[0]?.text || $json.text || $json.content || '',
    updated_at: new Date().toISOString()
  })
}}
```

---

## 🎯 この方式のメリット
1. **完全手放し自動化**: 国名が変数で入るため、国が変わってもURLを一切触る必要がありません。
2. **重複エラー（409）が物理的にゼロ**: 新規作成（POST）ではなく更新（PATCH）なので、キー重複エラーは100%起きません。
3. **過去データへの影響ゼロ**: リサーチ1や映画など過去に保存したセクションを誤って上書き・破損するリスクが完全に排除されます。
