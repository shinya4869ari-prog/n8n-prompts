# 📑 ★まとめ記事即時保存 ノード設定ガイド

n8nワークフロー上の **「★まとめ記事即時保存」**（HTTP Requestノード）の設定内容です。
`検索結果まとめ記事`（Gemini）から出力された5大特集解説（貿易・死因・犯罪・地理経済・物価）を、Supabase作業台テーブル（`country_research_cache`）の `summary_article` カラムへ安全にアップサート保存します。

---

## ⚙️ 基本設定

* **Node Name**: `★まとめ記事即時保存`
* **Method**: `POST`
* **URL**:
  ```text
  https://uvjpiuinsgklddzhzpio.supabase.co/rest/v1/country_research_cache?on_conflict=country
  ```

---

## 📋 Headers 設定

| Header名 | 値 | 役割・注意点 |
| :--- | :--- | :--- |
| `Prefer` | `resolution=merge-duplicates,return=minimal` | **重要**: `return=minimal` を指定することで、保存完了時に過去の全データ（映像作品やリサーチ1・2等）を送り返さず、空（204 No Content）で正常終了します。 |
| `apikey` | `sb_publishable_iW0cu7wjxn_rKjAd1O5Prg_tmecdAkX` | Supabase APIキー |
| `Authorization` | `Bearer sb_publishable_iW0cu7wjxn_rKjAd1O5Prg_tmecdAkX` | Bearerトークン |
| `Content-Type` | `application/json` | JSON送信指定 |

---

## 📦 JSON Body 設定

### 【推奨】Specify Body: `JSON` ➜ 「Expression」モードの場合
以下のコードブロックをそのまま「JSON」入力欄に貼り付けてください。  
`JSON.stringify()` で囲んでいるため、まとめ記事本文に改行や引用符（`"`）が含まれていても100%安全にJSONが構築されます。

```javascript
{{
  JSON.stringify({
    country: $('整形ノード1').first().json.country,
    country_code: $('整形ノード1').first().json.world_bank_code || 'ID',
    summary_article: $json.content?.parts?.[0]?.text || $json.text || $json.content || '',
    status: 'in_progress',
    updated_at: new Date().toISOString()
  })
}}
```

---

### 【別方式】Parameters（Key/Value 個別フィールド指定）の場合

もし Body を個別パラメータ（Fields）で1項目ずつ入力している場合は、以下のように設定します：

| Parameter (Key) | Value (Expression) |
| :--- | :--- |
| `country` | `{{ $('整形ノード1').first().json.country }}` |
| `country_code` | `{{ $('整形ノード1').first().json.world_bank_code \|\| 'ID' }}` |
| `summary_article` | `{{ $json.content?.parts?.[0]?.text \|\| $json.text \|\| $json.content \|\| '' }}` |
| `status` | `in_progress` |
| `updated_at` | `{{ new Date().toISOString() }}` |

---

## 🎯 保存されるカラム
* **`country`**: 対象国名（主キー）
* **`country_code`**: 国コード（例: `ID`）
* **`summary_article`**: 5大特集解説（貿易・死因・犯罪・地理経済・物価）のマークダウンテキスト
* **`status`**: `in_progress`
* **`updated_at`**: 保存日時
