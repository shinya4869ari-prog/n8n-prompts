【あらすじあり？ (Switch / IF ノード) 用コード】

※ n8nの条件設定が「Expressionモード（紫色のタブ）」になっている場合、末尾に `=== true` を付けることで、Resultが `false` の時に100%確実かつ強制的に 「false分岐（下側のBrave Searchルート）」 へ送ることができます。

```javascript
{{ (() => {
  let overview = '';
  try {
    overview = $json.overview || $('映画データ整形コード').item?.json?.overview || '';
  } catch(e) {}
  
  // あらすじ（overview）に文字が入っていれば true / 空っぽなら false
  return Boolean(overview && String(overview).trim().length > 10);
})() === true }}
```
