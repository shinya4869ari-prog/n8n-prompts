## 🎯 【今回の改善ゴール】
1. **「2回回す二度手間」の完全解消**:
   - `Country Fixed Data`（新規登録）と `Database_update`（最新化）を自動直結し、**1回ボタンを押すだけで最新データまで完走**させる。
2. **AIノードの超スリム化 ＆ 0円高速化**:
   - 3つぶら下がっていた検索ツール（Brave / Tavily / Perplexity）を全撤去し、**Gemini 3.8 Flash（Google検索内蔵）に一本化**する。
3. **スプレッドシートの重複防止（安全化）**:
   - `append`（追加）から **`appendOrUpdate`（更新または追加）** に変更し、何回実行してもデータが重複しないようにする。
4. **データ抽出コードの最新化**:
   - WPB・Numbeoの抽出コードを、エラーに強い最新バージョンに統一する。

## 🚀 【作業手順（ステップ順）】

### [STEP 1] AIノードのスリム化（検索ツール撤去 ＆ Gemini一本化）
- [x] キャンバスから **`Brave Search`**, **`Search in Tavily`**, **`Perplexity`** の3つのツールノードを削除する。
- [x] `固定データ Researcher` の設定を開き、ツール不要の **Gemini 3.8 Flash（Google Search有効）** に変更する。
- [x] プロンプト（`固定データ Researcher.md`）のTool使用ルール記述をスリム化する。

### [STEP 2] スプレッドシート書き込みの重複防止（append ➜ appendOrUpdate）
- [x] **`Google Sheets 書き込み（①経済）`** ノードを開く:
  - Operation を `append` ➜ **`appendOrUpdate`** に変更。
  - Matching Column（一致キー）に **`国名（日本語）`** を指定。
- [x] **`Google Sheets 書き込み（②治安）`** ノードを開く:
  - Operation を `append` ➜ **`appendOrUpdate`** に変更。
  - Matching Column に **`国名（日本語）`** を指定。
- [x] **`Google Sheets 書き込み（③物価）`** ノードを開く:
  - Operation を `append` ➜ **`appendOrUpdate`** に変更。
  - Matching Column に **`国名（日本語）`** を指定。


### [STEP 3] WPB・Numbeo 抽出コードの最新化
- [x] `Numbeoデータ抽出` コードを `Database_update` の最新堅牢版ロジックに同期する。
- [x] `ワールドプリズンブリーフデータ抽出` コードの動作を確認し、最新版に同期する。


### [STEP 4] 「Database_update (Sheet Only)」の作成 ＆ 自動キック接続
- [ ] **① `Database_update (Sheet Only)` ワークフローの作成**:
  1. n8n ワークフロー一覧で `Database_update` の右メニュー（縦3点リーダー）から **「Duplicate」** をクリック。
  2. ワークフロー名を **`Database_update (Sheet Only)`** に変更して保存。
  3. 右端にある **`サブワークフロー呼び出し（治安）`** と **`サブワークフロー呼び出し（物価）`** の2ノードを削除（※ブログ記事更新を実行させない安全化）。
  4. 先頭に **`Execute Workflow Trigger`** ノードを追加し、`フォーム入力→対象国フィルタ` に配線して保存。
- [ ] **② `Country Fixed Data` 側の呼び出し設定**:
  1. `書き込み国リスト更新`（または `管理シート更新Code`）の直後に **`Execute Workflow` ノード** を追加して配線。
  2. Workflow: **`Database_update (Sheet Only)`** を選択。
  3. Mode: **`Each Item`**
  4. 渡すパラメータ（Values to Send）:
     - Name: `targetCountry`
     - Value: `{{ $('国名マスター引当').item.json.country || $('プロンプト取得用 Code').item.json.country }}`
  5. キャンバス上の不要な古い残骸ノード（`Discord (Deactivated)` など）を削除して保存。
