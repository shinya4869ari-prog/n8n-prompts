# 📑 ★まとめ記事即時保存 ノード設定ガイド（今回保存分のみ表示・完全自動化）

n8nワークフロー上の **「★まとめ記事即時保存」**（HTTP Requestノード）の完全決定版設定です。

* 過去のデータ（地理や映画など）は一切触れず、**今回新しく生成された「まとめ記事」だけ** をピンポイント保存（PATCH）します。
* 空っぽ `[ {} ]` にならず、**アウトプット画面に「今回保存された国名とまとめ記事」だけが綺麗に返ってくる** ため、保存が成功したか一目で確認できます。

---

## ⚙️ 基本設定

* **Node Name**: `★まとめ記事即時保存`
* **Method**: **`PATCH`**
* **URL**:
  ```text
  https://uvjpiuinsgklddzhzpio.supabase.co/rest/v1/country_research_cache?country=eq.{{ $('国名変換Code').first()?.json?.country || $('まとめCode').first()?.json?.country }}&select=country,summary_article,updated_at
  ```
  ※`encodeURIComponent` は不要です（n8nが自動でエンコードするため、付けると二重エンコードになり0件ヒットして空っぽになります）。末尾の `&select=...` により、今回保存された項目だけがアウトプットに返ります。

---

## 📋 Headers 設定

| Header名 | 値 | 役割 |
| :--- | :--- | :--- |
| `Prefer` | `return=representation` | 今回保存した結果をアウトプット画面に表示する命令 |
| `apikey` | `sb_publishable_iW0cu7wjxn_rKjAd1O5Prg_tmecdAkX` | Supabase APIキー |
| `Authorization` | `Bearer sb_publishable_iW0cu7wjxn_rKjAd1O5Prg_tmecdAkX` | Bearerトークン |
| `Content-Type` | `application/json` | JSON送信指定 |

## 📦 JSON Body 設定

### Specify Body: `JSON` ➜ 「Expression」モード
```javascript
{{
  JSON.stringify({
    summary_article: $json.content?.parts?.[0]?.text || $json.text || $json.content || '',
    updated_at: new Date().toISOString()
  })
}}
```

## 🎯 ノード実行後のアウトプット（こう表示されます）

実行すると、n8nの右側アウトプット画面に以下のように表示されます：

```json
[
  {
    "country": "インドネシア",
    "summary_article": "## [貿易解説]：東南アジア最大の...",
    "updated_at": "2026-09-19T03:01:57.688Z"
  }
]
```

* **昔のリサーチャー1（地理）や映画などの無関係なデータは一切出ません**。
* **空っぽ `[ {} ]` にもなりません**。
* **今回保存されたデータだけ** が表示されるため、DBを見に行かなくても「ちゃんと入った！」と一目で分かります。
