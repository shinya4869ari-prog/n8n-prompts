# あらすじ判定ノード 設定 (If ノード)

## 📌 概要
TMDb から取得した `overview` に「日本語（ひらがな・カタカナ・漢字）」が含まれているかを正規表現で判定します。

---

## 🛠️ ノード設定パラメータ

| 設定項目 | 設定値 |
| :--- | :--- |
| **Node Name** | `あらすじ判定ノード` |
| **Value 1** | `{{ $('TMDb検索').item.json.overview }}` |
| **Operation** | `matches regex` (正規表現マッチ) |
| **Value 2** | `[\u3040-\u309F\u30A0-\u30FF\u4E00-\u9FAF]` |

---

## 🔀 分岐後の挙動
- **`true`（日本語あり）**:
  - TMDb にすでに公式の日本語あらすじが存在するため、AI（Claude）を実行せずにそのまま **`映画データ整形Code`** へ進みます（コスト＆時間ゼロ！）。
- **`false`（日本語なし / 英語・韓国語・空欄）**:
  - 日本語のあらすじが存在しないため、**`claude_movie_db`** へ進み、TMDb の英語・韓国語あらすじを元に自然な日本語あらすじを生成させます。
