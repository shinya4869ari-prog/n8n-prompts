# 01. 韓国ニュース取得・RSSフィード設計

## 📌 概要
本設計書は、韓国の最新ニュース（総合ニュースおよび各カテゴリ別トレンド）を全自動で取得するためのエンドポイントおよびクエリ定義です。

---

## 🌐 1. Google News 韓国版 RSS フィード (APIキー不要・完全無料)

Google News の韓国版 RSS は、常にリアルタイムで主要メディア（聯合ニュース、JTBC、KBS、SBS、朝鮮日報等）のトップ記事を配信しています。

### (A) 総合トップニュース（今週のハイライト用）
* **URL**: `https://news.google.com/rss?hl=ko&gl=KR&ceid=KR:ko`
* **取得形式**: XML (RSS 2.0)
* **n8n ノード**: `HTTP Request` (Method: `GET`, Response Format: `String` または `XML`) ➔ `XML to JSON` (または Codeノードで抽出)

### (B) カテゴリ別トピック検索 (Topic / Search クエリ)
Google News RSS の検索クエリパラメータを利用して、各カテゴリの重要ニュースをピンポイント抽出します：

1. 🚨 **犯罪・治安 (`crime`)**:
   `https://news.google.com/rss/search?q=%EC%82%AC%EA%B1%B4+%EC%82%AC%EA%B3%A0+OR+%EA%B2%BD%EC%B0%B0+OR+%EA%B2%80%EC%B0%B0+OR+%EC%9E%AC%ED%8C%90+when:7d&hl=ko&gl=KR&ceid=KR:ko`
   *(クエリ: `사건 사고 OR 경찰 OR 검찰 OR 재판 when:7d`)*

2. 🏡 **暮らし・社会 (`life`)**:
   `https://news.google.com/rss/search?q=%EB%AC%BC%EA%B0%80+OR+%EB%B6%80%EB%8F%99%EC%82%B0+OR+%EB%B3%B8%EC%A0%88+OR+%EA%B1%B4%EA%B0%95+when:7d&hl=ko&gl=KR&ceid=KR:ko`
   *(クエリ: `물가 OR 부동산 OR 복지 OR 건강 when:7d`)*

3. 🏛️ **政治 (`politics`)**:

## ⚙️ 2. n8n での RSS 抽出 Code ノード (JavaScript)

RSSのXML文字列からタイトル、リンク、発行日、概要テキストを抽出し、AI要約用のクリーンな配列を生成します：

```javascript
const rawXml = $input.first()?.json?.data || $input.first()?.json?.body || '';

const items = [];
const itemRegex = /<item>([\s\S]*?)<\/item>/gi;
let match;

while ((match = itemRegex.exec(rawXml)) !== null && items.length < 15) {
  const content = match[1];
  const title = (content.match(/<title>([\s\S]*?)<\/title>/i)?.[1] || '').replace(/<!\[CDATA\[(.*?)\]\]>/g, '$1').trim();
  const link = (content.match(/<link>([\s\S]*?)<\/link>/i)?.[1] || '').trim();
  const pubDate = (content.match(/<pubDate>([\s\S]*?)<\/pubDate>/i)?.[1] || '').trim();
  const description = (content.match(/<description>([\s\S]*?)<\/description>/i)?.[1] || '').replace(/<[^>]+>/g, '').trim();

  if (title) {
    items.push({
      title,
      link,
      pubDate,
      description
    });
  }
}

return items.map(item => ({ json: item }));
```
