# 🎵 韓国語歌詞・語学学習自動生成ワークフロー 構築手順書
〜 スクショ画像・楽曲ID対応 / iTunes & LRCLIB連携 / 公式歌詞自動取得 / AI対訳・発音・単語帳 / コスト算出 / Supabase自動保存 〜

## 📌 概要
本ワークフローは、**「YouTube等の画面スクショ画像」** または **「Apple Music / iTunes 楽曲ID」** のどちらからでも、手動コピペ一切不要で完全自動実行できる韓国語学習コンテンツ生成システムです。

1. **W入力対応（スクショ画像 or 楽曲ID直接）**:
   - **📸 スクショ画像**: Gemini Vision が画像から曲名・アーティスト名をOCR抽出し、iTunesで楽曲を特定
   - **🆔 楽曲ID**: 従来の `track_id`（例: `1681264206`）直接指定による即時実行
2. **iTunes 公式 API 連携**:
   - 曲名・アーティスト・アルバム名・600x600高解像度ジャケット・試聴音源URLを自動取得
3. **LRCLIB 公式歌詞自動取得 API 連携（完全自動）**:
   - iTunesで確定した曲名・歌手名から、無料の音楽歌詞API（LRCLIB）より韓国語の公式フル歌詞を一瞬で自動取得
   - AIによる勝手な作詞・省略・ハルシネーションを100%排除
4. **Google Gemini 3.7 Flash による学習教材生成**:
   - 公式歌詞に完全一致したフレーズごとのハングル (`ko`)
   - 日本語の自然で美しい対訳 (`ja`)
   - 日本人が読みやすいカタカナ発音ルビ (`rubi`)
   - 単語ホバー連動の重要単語帳 (`vocab`)
   - 歌詞に出てくる生きた文法・助詞 (`grammar`)
   - 楽曲背景・感情表現の深掘りノート (`lyrics_notes`)
5. **円換算コスト算出**:
   - 実行時の消費トークン数から「1曲あたり何円かかったか（約0.2円程度）」を瞬時に算出
6. **Supabase `tracks` テーブルへ自動保存**:
   - 韓国語学習アプリ「Korean-Learner」に即座に反映
