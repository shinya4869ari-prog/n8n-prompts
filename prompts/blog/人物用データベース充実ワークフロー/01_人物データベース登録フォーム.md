# 【01】人物データベース登録フォーム (Form Trigger)

## 📌 ノード概要
* **ノード名**: `人物データベース登録フォーム`
* **ノードタイプ**: `n8n-nodes-base.formTrigger`
* **役割**: ブラウザのフォームから手動で人物（俳優・監督・歌手・文化人など）を入力し、ワークフローを起動するトリガーノード。映画・ドラマワークフローからのWebhook連携やSupabase直接呼び出しにも対応。

---

## ⚙️ フォーム設定仕様 (Form Fields)

| フィールド名 (Field Name) | フォーム項目名 (Field Label) | タイプ (Type) | 必須 (Required) | 説明 / 入力例 |
| :--- | :--- | :--- | :---: | :--- |
| `name` | 人物名（日本語表記） | Text | **○** | 例: `イ・ジェフン`, `ソン・ガンホ`, `ポン・ジュノ` |
| `name_en` | 原語名（ハングル / 英語） | Text | - | 例: `이제훈`, `Lee Je-hoon` |
| `occupation` | 職業・ジャンル | Dropdown / Text | - | 例: `俳優`, `映画監督`, `歌手`, `脚本家` |
| `country` | 国コード | Text | - | 例: `KR` (デフォルト), `JP`, `US` |
| `wikidata_id` | Wikidata QID | Text | - | 例: `Q496314`（指定すると100%正確に照合可能） |
| `type` | 形態（個人 / グループ） | Dropdown | - | `individual` (個人) / `group` (グループ) |

---

## 📥 フォーム出力データ例 (JSON)

フォーム送信時に後続の `02_入力分割コード` へ渡されるデータの形式：

```json
{
  "name": "イ・ジェフン",
  "name_en": "이제훈",
  "occupation": "俳優",
  "country": "KR",
  "wikidata_id": "Q496314"
}
```

### 💡 映画ワークフロー等からの直接Webhook連携時（カンマ区切り一括受付）
```json
{
  "director": "チャン・フン",
  "director_en": "Jang Hoon",
  "cast": "シン・ハギュン, コ・ス, イ・ジェフン",
  "cast_en": "Shin Ha-kyun, Go Soo, Lee Je-hoon",
  "country": "KR"
}
```
※後続の `02_入力分割コード` により、カンマ区切りの複数人物が自動で1人ずつのアイテムに分割処理されます。
