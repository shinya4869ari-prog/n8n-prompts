# 🎵 05 LRCLIB 公式歌詞自動取得 API（ノード設定ガイド）

このノードは **JavaScript（Codeノード）ではなく、n8n の標準「HTTP Request」ノード** です。
iTunesで特定された楽曲名と歌手名をもとに、無料の歌詞API（LRCLIB）から公式歌詞を自動取得します。

---

## 📌 ノード基本情報
- **ノード種類**: `HTTP Request`
- **ノード名**: `LRCLIB 公式歌詞自動取得 API`
- **配置位置**: 
  - 入力元: `02_スクショ検索結果確定` および `04_ID検索結果確定` の両方から接続
  - 出力先: `06_iTunesレスポンス解析_Geminiリクエスト生成` へ接続

---

## ⚙️ ノードパラメータ設定
| 設定項目 | 設定値 | 補足 |
| :--- | :--- | :--- |
| **Method** | `GET` | |
| **URL** | `={{ $json.lrclib_search_url }}` | 前のノードで自動生成された検索URL |
| **Authentication** | `None` | APIキー不要（完全無料・登録なし） |
| **Never Error (エラー無視)** | `ON` (有効) | 万が一見つからなくても止まらずGeminiへ進む |

---

## 🔄 全体の接続フロー
```text
[02_スクショ検索結果確定] ──┐
                          ├──> [LRCLIB 公式歌詞自動取得 API (HTTP)] ──> [06_iTunesレスポンス解析_Geminiリクエスト生成]
[04_ID検索結果確定] ──────┘
```
