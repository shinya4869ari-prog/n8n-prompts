# 【韓国ニュース語学学習】n8n 自動巡回ワークフロー構築手順書（本格詳報・段落対訳対応版）

## 📌 概要
本ワークフローは、毎日定期実行（毎朝7時等）で以下を全自動で行います：
1. **Supabase からお気に入り人物（推し）の取得**
2. **Google News 韓国版 RSS から最新ニュース（6大カテゴリ ＋ 推しニュース）の取得**
3. **Gemini Flash による 3〜4段落（800〜1,200字）の本格報道記事再構成・韓日対訳・重要単語抽出**
4. **Supabase の `news` テーブルへの安全 Upsert**

---

## 🏗️ 全体フロー図

```text
[Schedule Trigger (毎朝7時)]
    │
    ├──▶ [HTTP Request (Google News 総合RSS)] ──┐
    │                                             │
    └──▶ [Supabase (Persons取得)]                 │
            │ (is_favorite=eq.true)               │
            ▼                                     ▼
         [推しニュース検索クエリ生成] ──▶ [HTTP Request (推しRSS)]
                                                  │
                                                  ▼
                                       [ニュースデータ統合 Code]
                                                  │
                                                  ▼
                         [Gemini Flash (本格長文報道・段落対訳・語学抽出)]
                                                  │
                                                  ▼
                                       [Supabase保存整形コード]
                                                  │
                                                  ▼
                                  [HTTP Request (Supabase news Upsert)]
```

### 3. `推しニュース検索クエリ生成`
* **Type**: `Code` (Run Once for All Items)
* **Code**: `02_推し人物ニュース検索.js` の内容をセット。

### 4. `Google News 取得ノード群` (HTTP Request)
* **Method**: `GET`

* **Model**: `gemini-1.5-flash` または `gemini-2.0-flash`

### 6. `Supabase保存整形コード`
* **Type**: `Code` (Run Once for All Items)
* **Code**: `04_Supabase保存整形コード.js` の内容をセット。

### 7. `Supabase news Upsert` (HTTP Request)

* **URL**: `https://uvjpiuinsgklddzhzpio.supabase.co/rest/v1/news`
* **Headers**:
