# 貿易データベース自動更新システム 運用マニュアル

このディレクトリには、UN Comtrade（国連）およびIMF（国際通貨基金）の最新データを自動取得し、Googleスプレッドシートの「④貿易」シートに一括反映するためのシステムが構築されています。

1年後や2年後にデータを最新版にアップデートしたい場合は、本手順に従って実行してください。

---

## 📋 事前準備

初回実行時のみ、以下の2つのキー（Comtrade APIキー ＆ GoogleスプレッドシートAPIキー）の取得が必要です。

### 1. 国連 Comtrade API キーの取得
1. [UN Comtrade Portal (API)](https://comtradeplus.un.org/) にアクセスし、無料アカウントを作成してサインインします。
2. サインイン後、APIの無料サブスクリプションプラン（通常は「Free」または「Preview」）に登録します。
3. プロフィールページ（またはサブスクリプション詳細）から、**`Primary Key` (Ocp-Apim-Subscription-Key)** をコピーして控えておきます。これが更新用APIキーになります。

### 2. Google Sheets API 認証キー（サービスアカウント）の取得
PythonからGoogleスプレッドシートを自動で書き換えるための鍵を作成します。

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスします。
2. プロジェクトを新規作成（または既存のプロジェクトを選択）します。
3. **Google Drive API** と **Google Sheets API** を検索して「有効にする」をクリックします。
4. `ナビゲーションメニュー` ＞ `IAM と管理` ＞ `サービス アカウント` を選択し、「サービスアカウントを作成」をクリックします。
5. サービスアカウント名を入力し、ロールは指定せず完了します。
6. 作成されたサービスアカウントの「メールアドレス（例: `my-sync-bot@xxxx.iam.gserviceaccount.com`）」をコピーして控えます。
7. 作成したサービスアカウントの `操作` ＞ `鍵の管理` ＞ `鍵を追加` ＞ `新しい鍵を作成` を選択し、**JSON形式**でダウンロードします。
8. ダウンロードした JSON ファイルの名前を **`credentials.json`** に変更し、この `Country Fixed Data` フォルダの直下に配置します。
9. 更新対象のGoogleスプレッドシートを開き、画面右上の「共有」ボタンから、上記6で控えた**サービスアカウントのメールアドレスを共有相手（「編集者」権限）として追加**します。

---

## 🚀 データベース更新の実行

準備が完了したら、以下の手順で一括更新を実行します。

### 1. 依存ライブラリのインストール（初回のみ）
ターミナルまたはPowerShellで以下を実行します。
```bash
pip install pandas numpy gspread google-auth requests
```

### 2. 更新スクリプトの実行
この `Country Fixed Data` ディレクトリに移動し、以下のコマンドを実行します。

```bash
python update_trade_database.py --api-key <取得したComtradeキー> --spreadsheet-id <スプレッドシートのID> --year <更新したい年>
```
* **`<取得したComtradeキー>`**: 事前準備1でコピーした国連のAPIキー。
* **`<スプレッドシートのID>`**: GoogleスプレッドシートのURL（`https://docs.google.com/spreadsheets/d/XXXXXXXXX/edit`）の `XXXXXXXXX` の部分。
* **`<更新したい年>`**: 最新の年（例：`2024` または `2025` など）。

### 💡 レジューム（途中再開）機能について
途中でAPIの回数制限などでエラーが発生して停止した場合、**翌日以降に全く同じコマンドを再実行**してください。
ダウンロード済みの国のデータは自動的にスキップされ、**未取得の国から処理が再開**されます。すべての国が揃った時点で、自動的にスプレッドシートへマージデータが同期されます。
