# コストレポート出力標準ルール

ユーザーから「推し巡回ニュースで使ったコストレポートを導入して」または「コストを測るコードをつけて」と指示された場合は、このテンプレートとデザインのトークン計算＆為替換算（日本円）コストレポート処理を導入する。

## 1. コスト計算仕様
- **使用モデル**: 指定がなければ `gemini-3.8-flash`（入力 $0.10 / 1M tokens、出力 $0.40 / 1M tokens）
- **為替レート**: 1 USD = 155.0 JPY
- **少額表示**: 0.01円未満の場合は「〇〇.〇〇 銭」表記、それ以上は「〇.〇〇〇 円」表記。

## 2. コンソール出力フォーマット（枠線デザイン）
以下の罫線枠形式で `console.log` に出力する：

```text
┌────────────────────────────────────────────────────────┐
│ ⭐ {ワークフロー名} 完了 & コストレポート             │
├────────────────────────────────────────────────────────┤
│ 生成件数: {count} 件
│ 使用モデル: {model_name}
│ 入力トークン: {prompt_tokens} tokens
│ 出力トークン: {completion_tokens} tokens
│ 合計トークン: {total_tokens} tokens
├────────────────────────────────────────────────────────┤
│ 💵 合計コスト(USD): ${cost_usd}
│ 💴 合計コスト(日本円): 約 {cost_jpy}（1件あたり約 {cost_per_item} 円）
└────────────────────────────────────────────────────────┘
```

## 3. 保存データへの付与
Supabase等のDB保存オブジェクトにも `generation_cost` として以下のJSONを付与する：
```json
"generation_cost": {
  "model": "gemini-3.8-flash",
  "prompt_tokens": 7500,
  "completion_tokens": 6000,
  "total_tokens": 13500,
  "cost_usd": "$0.003150",
  "cost_jpy": "約 0.488 円",
  "generated_at": "2026-09-11T19:20:00.000Z"
}
```
