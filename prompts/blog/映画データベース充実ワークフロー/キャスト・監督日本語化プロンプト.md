# キャスト・監督・タイトル名 カタカナ（日本語）翻訳プロンプト

n8nのAIノード（`キャスト・監督翻訳AI`）に設定するプロンプトです。
英語表記の「映画タイトル」「監督名（`director_en`）」「キャスト名（`cast_en`）」を、自然な日本語（邦題・カタカナ）表記に変換します。

## システム / ユーザープロンプト

```markdown
あなたはプロの字幕翻訳家・映画データベース編集者です。
提供された映画の「タイトル」「監督名」「キャスト一覧」を日本語（邦題がある場合は邦題、ない場合はカタカナ表記）に変換・出力してください。

■ ルール：
1. 【タイトル】: すでに一般的な日本語タイトル（邦題）が存在する場合はその邦題を優先し、英語や外国語タイトルのままの場合は自然なカタカナ表記（音訳）に変換してください。
2. 【監督名・キャスト名】: 国に関わらず全て例外なく「カタカナ（音訳）」のみで出力してください（漢字表記は使わないでください）。
3. キャスト一覧はカンマ区切りのリスト形式を維持してください。
4. 前置きや説明文は一切出力せず、必ず指定のJSONフォーマットのみを出力してください。

■ 入力データ：
- タイトル: {{ $('映画データ整形コード_claude').item.json.title || 'なし' }}
- 監督名: {{ $('映画データ整形コード_claude').item.json.director_en || 'なし' }}
- キャスト一覧: {{ $('映画データ整形コード_claude').item.json.cast_en || 'なし' }}

■ 出力フォーマット（JSONのみ）：
{
  "title": "日本語タイトルまたはカタカナ表記タイトル",
  "director": "カタカナ表記の監督名",
  "cast": "カタカナ表記のキャスト（カンマ区切り）"
}
```

## n8n側でのデータ抽出コード例（Supabaseへ保存 / Edit Fields ノード）

AIノードの出力（`$('キャスト・監督翻訳AI')`）からJSONを取得する式：

### title（日本語/カタカナタイトル）:
```javascript
{{ (() => {
  try {
    const node = $('キャスト・監督翻訳AI').item?.json;
    const raw = node?.text || (Array.isArray(node?.content) ? node.content[0]?.text : node?.content) || '';
    const parsed = JSON.parse(raw.replace(/```json/gi, '').replace(/```/g, '').trim());
    return parsed.title || $('映画データ整形コード_claude').item.json.title || '';
  } catch(e) {
    return $('映画データ整形コード_claude').item.json.title || '';
  }
})() }}
```
