以下の文章に登場する「地名・国名・都市名・地域名」「人物名」「重要キーワード」「映像作品・映画」「重大犯罪事件」を抽出し、指定のテキスト形式のみを出力せよ。

# 抽出の重要ルール（厳守）
1. **places（地名・地域名）**：
   - 特徴、歴史的背景を必ず「info」に含めてください。
   - 現在の国名だけでなく、**歴史的な呼称や地域名（例：ルアンダ＝ウルンディ、ザイール共和国など）**も漏らさず抽出してください。
   - 【厳禁】「〜語」で終わる単語（フランス語・英語・スワヒリ語・キニヤルワンダ語など）は絶対にplacesに含めないこと。言語名はkeywordsにも含めないこと。完全に除外すること。
   - 言語名は places に含めないこと
   - 主要貿易相手国（トップ10）として表に含まれるすべての国名、および文章中に登場するすべての地名・国名を漏らさず places に含めてください。

2. **people（人物名）**：
   - 肩書き、経歴、この文章での役割を「info」に記述してください。
   - フルネームだけでなく、**役職（大統領、首相、少将、中将など）**が付随している場合も含めて特定してください。
   - 主要な歴史的人物は必ず含めてください（例：ジュベナル・ハビャリマナ少将、ジャスティン・ンセンギユムヴァ首相など）。

3. **keywords（キーワード）**：
   - 重要概念、制度、略語などの定義や文脈を「info」に記述してください。

4. **crimes（重大犯罪事件）**：
   - 文章中に登場する重大犯罪事件・連続殺人事件のタイトル・事件名を漏らさず抽出してください。
   - 「info」には事件の概要・被害者属性・犯人名・判決を記述してください。
   - 事件名は記事中に登場する表記を優先すること。括弧内の読み仮名（例：（キム・ヘソン））が含まれている場合は、それも含めたフルの表記で出力すること。

5. **movies（映像作品・映画）**：
   - 文章中に登場する映画やドキュメンタリーなどの映像作品のタイトルを漏らさず抽出してください。

6. **命名形式（厳守）**：
   - 記載する場所・国名は、必ず日本語のみで表記してください。英語表記・括弧付き英語は絶対に含めないこと。

# 出力形式
- マークダウンや余計な説明、コードブロック（```text など）は一切出力せず、以下のテンプレート形式のみで出力してください。
- 各セクション名（===places=== など）を必ず行頭に置き、その下に「名前|説明」の形式で1行ずつ出力してください。
- 各項目の説明（info）には文字数制限はありません。詳細かつ的確に記述してください。

# 出力テンプレート
===places===
国名や地名（日本語のみ）|説明
===people===
人物名|説明
===keywords===
キーワード|説明
===movies===
映画や映像作品のタイトル|説明
===crimes===
事件名|説明
