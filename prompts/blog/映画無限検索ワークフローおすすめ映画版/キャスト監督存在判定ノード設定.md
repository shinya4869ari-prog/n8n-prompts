# キャスト・監督存在判定ノード 設定 (If ノード)

## 📌 概要
映画保存後に、監督（`director`）またはキャスト（`cast`）が存在するかを判定します。
未公開作品などで人物データが空（`null`）の場合は人物抽出・Wikidata検索を安全にスキップし、ワークフローやループが途中で止まるのを防ぎます。

---

## 🔀 配置と接続

```text
[Supabaseへ保存 (映画)]
          ⬇
[キャスト・監督あり？ (Ifノード)]
      ├── true  ➡ [キャスト・監督抽出] ➡ [Wikidata人物検索] ➡ ... ➡ (ループへ)
      └── false ➡ 人物処理をスキップして、そのまま (ループ / 次の処理へ)
```

---

## 🛠️ ノード設定パラメータ（手動設定時）

| 設定項目 | 設定値 |
| :--- | :--- |
| **Node Name** | `キャスト・監督あり？` |
| **Value 1 (Expression)** | `={{ Boolean($json.director || $json.cast) }}` |
| **Operation** | `Equal to` (Boolean) |
| **Value 2** | `true` |
