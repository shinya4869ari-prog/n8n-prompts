# 【01】人物データベース登録フォーム (Form Trigger)

## 📌 ノード概要
* **ノード名**: `人物データベース登録フォーム`
* **ノードタイプ**: `n8n-nodes-base.formTrigger`
* **役割**: ブラウザのフォームから手動で人物（俳優・監督・政治家・歴史上の人物・芸能人・文化人など）を入力し、ワークフローを起動するトリガーノード。映画・ドラマワークフローや韓国ニュースワークフローからのWebhook連携にも完全対応。

---

## ⚙️ フォーム設定仕様 (Form Fields)

| フィールド名 (Field Name) | フォーム項目名 (Field Label) | タイプ (Type) | 必須 (Required) | 説明 / 入力例 |
| :--- | :--- | :--- | :---: | :--- |
| `name` | 人物名（日本語表記） | Text | **○** | 例: `イ・ジェフン`, `尹錫悦`, `安重根`, `NewJeans` |
| `name_en` | 原語名（ハングル / 英語 / 漢字） | Text | - | 例: `이제훈`, `윤석열`, `Lee Je-hoon`, `Yoon Suk-yeol` |
| `occupation` | 職業・ジャンル | Dropdown / Text | - | 下記の選択肢から選択または自由入力 |
| `country` | 国コード | Text | - | 例: `KR` (韓国), `JP` (日本), `US` (米国), `KP` (北朝鮮) |
| `wikidata_id` | Wikidata QID | Text | - | 例: `Q496314`（指定すると同姓同名の誤判定なく100%正確に特定） |
| `type` | 形態（個人 / グループ） | Dropdown | - | `individual` (個人) / `group` (グループ・政党・劇団) |

### 🎭 職業・ジャンルの推奨選択肢 (Dropdown Options)
1. `俳優・タレント`（映画俳優、ドラマ俳優、舞台俳優など）
2. `映画監督・演出家・脚本家`
3. `政治家・首長・官僚`（大統領、国会議員、首相、知事など）
4. `歴史上の人物・独立運動家・軍人`（朝鮮王朝、近代史、革命家など）
5. `歌手・K-POPアイドル・グループ`
6. `コメディアン・アナウンサー・司会者`
7. `作家・詩人・学者・文化人`（小説家、研究者、ジャーナリストなど）
8. `スポーツ選手・アスリート`

---

## 📥 フォーム出力データ例 (JSON)

### 例1: 政治家を入力した場合
```json
{
  "name": "尹錫悦",
  "name_en": "윤석열",
  "occupation": "政治家",
  "country": "KR",
  "wikidata_id": "Q108741382"
}
```

### 例2: 歴史上の人物を入力した場合
```json
{
  "name": "安重根",
  "name_en": "안중근",
  "occupation": "歴史上の人物・独立運動家",
  "country": "KR",
  "wikidata_id": "Q334342"
}
```

### 例3: K-POPグループ・芸能人を入力した場合
```json
{
  "name": "NewJeans",
  "name_en": "뉴진스",
  "occupation": "歌手・アイドル",
  "country": "KR",
  "type": "group"
}
```

### 例4: 映画・ドラマワークフローからの複数一括連携時
```json
{
  "director": "チャン・フン",
  "director_en": "Jang Hoon",
  "cast": "シン・ハギュン, コ・ス, イ・ジェフン",
  "cast_en": "Shin Ha-kyun, Go Soo, Lee Je-hoon",
  "country": "KR"
}
```
